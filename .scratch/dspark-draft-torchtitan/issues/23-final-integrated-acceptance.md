# 23: 完成并行能力与性能优化的最终联合验收

**What to build:** 项目维护者获得最终可复现的 Qwen dense 与 GLM MoE draft 训练交付，能够判断每种已支持并行布局在选定性能配置下的更新正确性、完整阶段恢复能力和实际全流程成本。

验收以母规格《保持 DSpark 训练语义的 TorchTitan draft 并行适配与阶段卸载》及 ADR-0001/0002/0003 为准，保留现有 DSpark 训练语义、draft/target 边界和运行环境。

**Blocked by:** 20：扩展 MoE 规模并验证 EP 与 expert FSDP 组合；21：调优 SAC 与 FSDP 训练执行；22：减少阶段保存与恢复开销。

**Status:** ready-for-agent

- [ ] 整合已完成的 dense 支持矩阵、MoE EP/expert FSDP 扩展及票 21/22 选定优化；以最终配置为准，明确哪些优化适用于哪些模型和拓扑，不将独立通过结果直接当作组合通过。
- [ ] 每种最终宣称支持的组合都有真实训练入口的固定 features 更新对照，以及完整 update、DCP 提交、全部 GPU draft 状态卸载、同拓扑恢复和下一次 update 的证据；沿用未受影响的已有证据，补测新增组合与实际回归风险。
- [ ] 最终数值验收覆盖不等 microbatch 分母、GAS 不小于 2、各项完整 DSpark loss、全部可训练梯度、clip norm、master weights、Adam/scheduler 和 RNG/样本进度；专家及可微 pipeline context 路径分别有对应证据。
- [ ] 保有单机八卡真实 Qwen draft 尺寸、128K 输入及阶段交接的验收；其他 dense/MoE 组合按已验证规模和上下文报告，不扩大支持声明，也不以 tiny、CPU/toy 或 skip 替代真实 GPU 结果。
- [ ] 最终配置下验证新进程恢复、真实保存/提交失败后可恢复入口、滚动保留、按需 HF 可用导出及多阶段资源释放；同步提交后才卸载和交接的时序不变。
- [ ] 核对最终 draft 配置不会改变 target/vLLM 的现有解释器、源码、编译产物、依赖、推理配置、生产布局与监督契约，保留 DeepSpec 对外层训练循环的控制。
- [ ] 交付可复现配置、运行方式、实际 GPU/rank 数、模型规模、拓扑、软件构建、固定工作量、容差依据及支持/限制矩阵；每个候选的未完成或失败项明确呈现并处理，不用报告替代实现验收。
- [ ] 性能报告同时给出旧常驻路径参考、满足卸载契约的基础实现和最终选定实现的 draft 训练/保存/卸载/恢复分项及总耗时，包含首次初始化/编译、后续缓存命中、HF 实际导出、显存和测量波动。
- [ ] 所有性能比较固定逻辑训练配方，以多卡关键路径计时，排除 target 特征生产及等待，不对不同 DP/GAS 的行直接宣称同目标速度优劣，不预设或虚构加速比。
