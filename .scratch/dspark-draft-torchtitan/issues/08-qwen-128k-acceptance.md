# 08: 完成八卡真实 Qwen 128K 首阶段验收

**What to build:** 交付首阶段可复现的八卡 Qwen3.8 DSpark 训练方案，在真实 draft 尺寸与 128K 输入下完成 SelectiveAC、完整阶段卸载和持久化恢复，并提供符合目标口径的性能基线。

验收以母规格《保持 DSpark 训练语义的 TorchTitan draft 并行适配与阶段卸载》及 ADR-0001/0002/0003 为准，保留现有 DSpark 训练语义、draft/target 边界和运行环境。

**Blocked by:** 06：Qwen 阶段间完整卸载并恢复 GPU 训练状态；07：滚动保留 checkpoint，并按需导出 HF 权重。

**Status:** ready-for-agent

- [ ] 先使用短序列真实模型完成数值与恢复对照，再在单机八个实际 GPU/rank 上运行真实 Qwen draft 尺寸及 128K 输入；记录 5 个 draft layers、24 个 Q heads、4 个 KV heads 等实际模型配置，不能用 tiny/smoke 或 skip 替代。
- [ ] 从 DP shard2 × TP4、CP1 的候选 D 开始，保留既有训练配方与 producer 配置；若候选受限，记录具体原因并回到设计讨论，不通过缩小目标规模或改变训练语义宣称首阶段通过。
- [ ] 真实规模运行覆盖完整 optimizer update、同步 DCP 提交、完整 GPU 卸载、下一阶段恢复及继续 update；验证样本/RNG/进度连续、显存释放及既有 target/draft 交接。
- [ ] 计时分别覆盖 draft 训练、保存、卸载和恢复：训练包含已就绪 features 读取/搬运及真实更新，保存包含 DCP 提交和实际 HF 导出，恢复包含模型/并行化/optimizer 重建与加载。
- [ ] 初始化、首次编译及后续缓存命中按实际发生位置计入训练或恢复并单列；各计时互不重复、覆盖异步 GPU 工作完成，以多卡关键路径计时，不能简单累加同时发生的各 rank 时间。
- [ ] 排除 target features 生产及等待生产完成的时间，比较固定工作量下旧常驻路径参考与满足完整卸载契约的基础实现，分别报告生命周期成本和组件影响。
- [ ] 报告分项及总耗时、稳态吞吐、首次/后续阶段成本、峰值/卸载后显存、实际工作量与软件构建；不预先承诺加速比，也不把稳态吞吐当作总流程收益。
- [ ] 归档可复现配置、运行方式、基线容差依据及真实通过证据，完成首阶段门槛后才开始后续 dense 并行能力交付。
