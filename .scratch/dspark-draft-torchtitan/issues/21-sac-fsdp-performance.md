# 21: 调优 SAC 与 FSDP 训练执行

**What to build:** 性能工程师能够在首阶段通过后，使用可复现的固定工作量比较 SAC 保存策略和 FSDP 执行设置，采用确有收益的配置降低 draft 总耗时，同时保留数值与阶段恢复正确性。

验收以母规格《保持 DSpark 训练语义的 TorchTitan draft 并行适配与阶段卸载》及 ADR-0001/0002/0003 为准，保留现有 DSpark 训练语义、draft/target 边界和运行环境。

**Blocked by:** 08：完成八卡真实 Qwen 128K 首阶段验收。

**Status:** ready-for-agent

- [ ] 以票 08 的真实八卡 128K 与完整卸载基础实现为基线；本票可在首阶段后开始，不必等待所有 dense/MoE 能力完成，最终组合由票 23 验收。
- [ ] 依据实际分项计时和资源使用确定瓶颈，分别评估 SAC 保存策略、FSDP child reshard、forward/backward 预取及深度，记录候选设置和未采用原因，避免一次同时变更多个因素而无法解释收益。
- [ ] 固定 target features、样本顺序、逻辑 microbatch/update 分组、GAS、anchors、loss 系数、冻结集合、参数与通信精度及 optimizer/LR 配方，不通过改变训练目标获取吞吐收益。
- [ ] 对拟采用配置运行真实模型数值对照，包含不等有效分母、GAS 不小于 2、至少两次 updates 及 SAC 重计算 RNG，比较各 loss、全部可训练梯度、clip norm、master weights 和 Adam/scheduler。
- [ ] 每个拟采用配置验证同步 DCP、完整 GPU 卸载、同拓扑恢复及下一次 update，多阶段运行无预取/通信/参数状态残留增长，保存失败仍阻止下一 target 阶段。
- [ ] 记录多卡关键路径的训练、保存、卸载、恢复分项与总耗时，包含初始化及编译实际成本，排除 target 生产和等待；同时报告峰值/卸载后显存和重复测量波动。
- [ ] 仅将有数值与性能证据的改进纳入选定配置，无稳定收益的候选可保留基线并报告测量结论；不预设加速比，也不把稳态 step 提升直接当作全流程提升。
- [ ] 明确实际验证的模型、拓扑和开关适用范围，后续新并行组合不能自动继承性能配置的通过结论。
